Core Principles

Independent vs. Dependent Variables

Understanding the roles of X and Y in regression modeling.

X: Independent Variable

Years of Experience

Its values vary independently. It is the input provided to the system. The model uses this variable to compute predictions.

Y: Dependent Variable

Annual Salary (INR/Year)

Its value depends on the value of X. In most real-world contexts, a person's salary depends heavily on their experience.

Connecting to Machine Learning: The straight line has discovered and encoded the relationship between X and Y. Fitting data points to a straight line to capture this relationship is called Linear Regression.
Mathematical Formulation

The Equation of a Straight Line

Transitioning from graphical intuition to exact equations using Example 2.

Example 2 Dataset (5 Coordinates):
X Y Coordinate (X, Y)
15(1, 5)
27(2, 7)
39(3, 9)
411(4, 11)
513(5, 13)
y = mx + c

y: Value on Y-axis (Dependent variable)

x: Value on X-axis (Independent variable)

m: Slope (determines the line's orientation and tilt)

c: Intercept (distance from origin where the line cuts the Y-axis)

Step-by-Step Derivation

Calculating the Slope (m)

Slope determines the orientation of the line and rate of change.

Slope Formula:
m = (y₂ - y₁) / (x₂ - x₁)

Substitute Point 1 and Point 2:

P₁ = (2, 7) → x₁ = 2, y₁ = 7

P₂ = (3, 9) → x₂ = 3, y₂ = 9

m = (9 - 7) / (3 - 2) = 2 / 1 = 2
Physical Interpretation of m = 2

For every 1 unit increase in x, the value of y increases by 2 units.

Differential Notation:
dy / dx = 2

If dx = 1 → dy = 2. Consistent across any pair: e.g., (1, 5) and (4, 11) → (11 - 5) / (4 - 1) = 6 / 3 = 2.

Step-by-Step Derivation

Finding the Intercept (c)

The intercept is the vertical distance from origin to where the line starts on the Y-axis.

Graphical & Algebraic Value

Graphically: In our plot, the line crosses the Y-axis at y = 3 when x = 0.

Algebraic Verification:

With m = 2 → y = 2x + c

Substitute Point (4, 11) where x = 4, y = 11:

11 = (2 × 4) + c
11 = 8 + c
c = 11 - 8 → c = 3
The Exact Line Equation:
y = 2x + 3

If c were 4, the line would start at 4. If c were 7, it would start at 7. Here, because c = 3, the line starts at 3.

Inference Function

Making Predictions with the Equation

The line equation maps input x to predicted output y.

Prediction Example: x = 3.5

Plug the value of x into the derived equation:

y = 2(3.5) + 3

y = 7 + 3

y = 10

Graphically, drawing a vertical line at x = 3.5 meets the line at exactly y = 10.

Demystifying Machine Learning

Machine learning is fundamentally straightforward:

  • • We fit a line or curve to data to capture the trend.
  • • We use this learned function to predict y values for new x values.
  • • When a straight line is used, it is called Linear Regression.
Scaling Up

What If There Are More Than Two Variables?

Transitioning from Simple Linear Regression to Multiple Linear Regression.

Definition

"Multiple Linear Regression is a model for predicting the value of one dependent variable based on two or more independent variables."

In Simple Linear Regression, we had only 1 independent variable (experience) and 1 dependent variable (salary). In real-world applications, outcomes depend on multiple factors simultaneously.

Multiple Linear Regression Example

Experience + Qualification → Salary

What if salary depends on both Years of Experience AND Educational Qualification?

The Real-World Scenario

Candidate A:

B.E. / B.Tech in Computer Science with 2 years experience.

Candidate B:

M.E. / M.Tech in Computer Science with 2 years experience.

Logically, Candidate B (with a Master's degree) will get a higher salary despite both having 2 years of experience.

Dimensional Geometry: Hyperplanes

2 Variables: Modeled by a 2D Straight Line
3+ Variables: Modeled by a 3D Plane / Hyperplane

The model fits a multi-dimensional plane to capture relationships across all independent axes.

Mathematical Comparison

Simple vs. Multiple Linear Regression Equations

Comparing equations for single and multi-feature models.

Simple Linear Regression (1 Feature)
y = b₀ + b₁x₁

Identical to y = c + mx:

  • • b₀: Intercept (c)
  • • b₁: Slope / weight parameter (m)
  • • x₁: Single independent variable
Multiple Linear Regression (N Features)
y = b₀ + b₁x₁ + b₂x₂ + ... + bₙxₙ

Used when datasets contain multiple features:

  • • b₀: Intercept
  • • b₁, b₂, ... bₙ: Parameters / weights for features
  • • x₁, x₂, ... xₙ: Multiple independent features
Model Strengths

Advantages of Linear Regression

Why Linear Regression is one of the most widely used foundational algorithms.

01

Simple to Understand and Implement

We do not need an overwhelming number of parameters. In simple linear regression, we only need the slope and the intercept. It is computationally lightweight, transparent, and easy to interpret.

02

Performs Exceptionally on Linear Data

When data exhibits a true linear relationship (as experience increases, salary increases proportionally), you do not need complex algorithms like Random Forests or Deep Neural Networks. A simple straight line achieves optimal performance.

Limitation 1

Not Suitable for Non-Linear Data

A straight line fundamentally cannot model non-linear relationships.

Example: Sine Curve (t vs. y)

When x increases, y first increases, then decreases, increases again, and decreases.

The Problem:

No matter how you tilt or rotate a straight line, it cannot fit these points. Most real-world problems and data are non-linear, where linear regression cannot be used.

Limitations 2 & 3

Underfitting & High Sensitivity to Outliers

Examining two critical failure modes in linear regression.

Limitation 2: Underfitting

Inability to Capture Underlying Patterns

Underfitting occurs when a model is too simple / general to capture the pattern in the data (high bias).

Example: Fitting a horizontal straight line across the sine wave. The line completely fails to fit the sinusoidal trend, leading to massive bias and errors.
Limitation 3: Outliers

Extreme Sensitivity to Noise

Outliers are anomalous points that deviate heavily from the rest of the dataset.

Example:

Out of 10 data points, 8 follow the trend, but 2 are distant outliers. Those 2 outliers heavily distort and pull the regression line away from the genuine trend.

The Missing Bridge

Why Do We Need Loss & Gradient Descent?

Connecting our earlier line-fitting intuition to the algorithmic learning process.

1. Real Data Is Noisy

In real datasets, points rarely lie perfectly on one straight line. The salary example already shows this: one point sits slightly away from the main trend.

2. Two Points Aren't Enough

Two points can determine a line exactly, but with many noisy points there are many possible pairs — and different pairs can produce different lines. We need a rule that uses all the data.

3. Define “Best Fit”

We measure the total prediction error with a loss function and search for the parameter values that make that loss as small as possible.

Why Gradient Descent? It is one way to efficiently search for the parameter values that minimize the loss. For linear regression, an exact closed-form solution (Ordinary Least Squares / Normal Equation) also exists; Gradient Descent is useful to learn because the same optimization idea extends to models where no closed-form solution is available.

Data → Loss → Optimize
Mathematical Understanding • Part 2

The Algorithmic Challenge: Finding the Best Line

How does a machine learning algorithm know which candidate line is best?

Multiple Candidate Models

A human can look at the graph and sketch a best fit line. But a model cannot find the best fit in its first try.

How does the model compare lines?

Each candidate line has different parameters $(m, c)$. To determine which line is optimal, the model calculates the Loss Function.

Error Quantification

The Loss Function: Definition & Purpose

Measuring how far estimated values deviate from true data points.

Definition

A Loss Function measures how far an estimated (predicted) value is from its true (actual) value.

True Value (y): The actual target values present in the dataset.

Predicted Value (ŷ): The values estimated by our model equation ŷ = mx + c.

Why It Matters

  • • It tells us which candidate model performs better and which parameters are superior.
  • • High Loss: Large discrepancy → low model accuracy.
  • • Low Loss: Predictions are very close to actual data → high accuracy.
Mathematical Formula

Mean Squared Error (MSE) Formula

The standard metric for quantifying regression loss.

Loss Formula:
Loss = (1/n) ∑ (yi - ŷi)²

• yi: True actual value for point i.

• ŷi: Predicted value from line (ŷ = mx + c).

• n: Total number of data points.

Why Do We Square the Differences?

If ŷ = 15 and y = 10, the error (y - ŷ) is -5 (negative error).

Preventing Cancellation:

Without squaring, positive and negative errors would cancel each other out, making a poor model appear to have zero error. Squaring eliminates negative signs and penalizes larger deviations.

Step-by-Step Calculation

Loss Calculation Example: Initial Model (m = 3, c = 2)

Evaluating initial random parameters with model line: ŷ = 3x + 2.

Point x True y Predicted ŷ = 3x + 2 Error (y - ŷ) Squared Error (y - ŷ)²
12103(2) + 2 = 810 - 8 = 22² = 4
23143(3) + 2 = 1114 - 11 = 33² = 9
34183(4) + 2 = 1418 - 14 = 44² = 16
45223(5) + 2 = 1722 - 17 = 55² = 25
56263(6) + 2 = 2026 - 20 = 66² = 36
Sum of Squared Errors: 4 + 9 + 16 + 25 + 36 = 90
Loss = 90 / 5 = 18
Model Evaluation

Interpreting Loss & Iterative Adjustment

Why a loss value of 18 drives the model to update its parameters.

Analysis of Loss = 18

A loss of 18 is substantially high. The line ŷ = 3x + 2 fails to fit the upper cluster of data points well.

High loss indicates that the initial parameters (m=3, c=2) are not optimal. The model must adjust these parameters to reduce the loss.

The Iterative Optimization Cycle

Iteration: Repeating an operation multiple times.

  • • The model updates m and c repeatedly over multiple iterations.
  • • As parameters adjust, the loss decreases systematically.
  • • When loss reaches its lowest point, the model has converged on the best fit.
Optimization • Part 3

The Loss Surface & Global Minimum

Visualizing a simplified 1D cross-section of the convex loss surface.

The Global Minimum

With two parameters (m and c), the full loss surface is a 3D bowl over the (m, c) plane. This sketch shows a 1D cross-section of that surface, so we can see the descent into the valley more easily.

The Lowest Point:

The deepest point on this curve is the Global Minimum. Parameters at this point yield the lowest loss. If you increase or decrease parameters beyond this valley, loss rises.

Algorithm Mechanics

Gradient Descent: Parameter Update Rules

How Gradient Descent navigates down the loss surface to the minimum.

Update Equations:
m = m - L × dm
c = c - L × dc

Used in loops to repeatedly step down the slope towards the minimum.

Term Definitions

  • • m, c: Current slope and intercept values.
  • • L: Learning Rate (scales the gradient to determine the update).
  • • dm: Partial derivative of loss with respect to m (∂Loss / ∂m).
  • • dc: Partial derivative of loss with respect to c (∂Loss / ∂c).
Hyperparameter Tuning

The Learning Rate (L): Controlling Step Size

The magnitude of the change made to parameters during each iteration.

Concept & Example

The learning rate L is chosen first. The actual parameter update is determined by L × gradient. For example, if dm = 20 and L = 0.001, then the update to m is 0.001 × 20 = 0.02.

Learning rate controls how strongly the computed gradient changes the parameters at each iteration.

The Trade-off

Too Large: May overshoot the global minimum and fail to converge.
Too Small: Extremely slow steps requiring an excessive number of iterations.
Calculus Derivation

Mathematical Derivation of dm and dc

Differentiating the Loss Function with respect to m and c via the Chain Rule.

Partial Derivative for Slope (dm):
dm = -(2/n) ∑ xi(yi - ŷi)

Differentiating [yi - (mxi + c)]² with respect to m pulls down 2, multiplies by inner derivative (-xi), and averages over n points.

Partial Derivative for Intercept (dc):
dc = -(2/n) ∑ (yi - ŷi)

Differentiating with respect to c pulls down 2, multiplies by inner derivative (-1), and averages over n points.

Terminology note: this deck uses Loss Function for the averaged MSE over the dataset; some courses call the same quantity the Cost Function.
Synthesis

Summary & The Complete Learning Loop

The 6-step iterative execution cycle of Linear Regression.

1. Initialize

Assign random initial parameters for m and c.

2. Predict

Compute predictions ŷi = mxi + c.

3. Compute Loss

Evaluate MSE: (1/n) ∑ (yi - ŷi)².

4. Compute Gradients

Calculate partial derivatives dm and dc.

5. Update Weights

Apply m = m - L·dm, c = c - L·dc.

6. Converge

Iterate until Global Minimum is achieved.
